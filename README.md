

# 🚗 Car Database Management System – A Full DevOps Journey

This project is a complete **web application** built to demonstrate a real-world **DevOps workflow** — from local development and version control to live deployment. It features a secure login system, an interactive dashboard showcasing premium sports cars, and a fully responsive design with advanced search functionality.

---

## 🎯 **Project Overview**

The **Car Database Management System** is a front-end web application that simulates a secure, data-driven dashboard for browsing high-end sports cars. It highlights:

- 🔐 **Secure Authentication** (admin/password)
- 📊 **Interactive Dashboard** with detailed car information
- 🔍 **Advanced Search** by name, country, engine, or price
- 📱 **Fully Responsive Design**
- 📦 **Complete Git & GitHub Workflow**
- 🌐 **Live Deployment** on GitHub Pages

---

## 🛠️ **Tech Stack**

- **HTML5** – Structure
- **CSS3** – Styling & Responsive Design
- **JavaScript (ES6)** – Logic & Interactivity
- **Git & GitHub** – Version Control & Hosting

## 📘 **Git Commands Used in This Project**

Here’s a step-by-step breakdown of the Git workflow implemented:

### 1. **Initialize Repository**
```bash
git init
```

### 2. **Create Project Files**
```bash
touch index.html dashboard.html style.css script.js cars-data.json
echo "# Car Database Project" > README.md
```

### 3. **Stage Changes**
```bash
git add .                     # Stage all files
# or
git add index.html            # Stage specific file
```

### 4. **Commit Changes**
```bash
git commit -m "Created login page with authentication"
```

### 5. **Check Status & History**
```bash
git status
git log --oneline            # Compact commit history
```

### 6. **Branching**
```bash
git checkout -b feature-search   # Create and switch to new branch
git branch                       # List branches
git checkout main                # Switch back to main
```

### 7. **Connect to GitHub**
```bash
git remote add origin https://github.com/Hemanth870-tech/car-database.git
git branch -M main
git push -u origin main
```

### 8. **Push Updates**
```bash
git push origin main
```
